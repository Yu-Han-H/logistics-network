## 2. 包边界

| 包 | 放什么 | 不放什么 |
|---|---|---|
| `controller` | 参数接收、`@Valid`、调 Service、包 `Result` | 算法、数据结构、SQL |
| `service` | 业务编排、唯一写入口、`graphVersion`、DTO 映射 | HTTP 细节、页面逻辑 |
| `dto` | 对外字段、请求体、响应体 | 链表指针、内部 `Edge` |
| `common` | `Result`、`ResultCode`、`FieldError`、全局异常 | 业务逻辑 |
| `auth` | `Role`、`RequireRole`、`AuthInterceptor` | 用户数据 |
| `config` | `WebConfig`（拦截器、CORS） | 算法 |
| `exception` | 自定义异常 | 全局处理器（在 `common`） |
| `structure` | `CityNode`、链表、图 | Spring 注解、Controller |
| `algorithm` | Prim、Kruskal、UnionFind、Dijkstra | DTO、HTTP |

依赖只能从上往下：`controller → service → structure/algorithm → model`。反过来不行。

## 3. Service 方法签名

### 3.1 CityService（梁敬谦）

```java
List<CityDTO> list();
CityDTO get(int id);
CityDTO add(CityRequest request);
CityDTO update(int id, CityRequest request);
void delete(int id);
SortedCitiesDTO sorted(Integer referenceId);
void reset();
int version();
```

实现要点：

- 启动时读 `src/main/resources/data/cities.txt`，UTF-8，3 列，30 条；id = `1000 + 有效数据行号`。
- 内部持有 `DoublyCircularLinkedList` 和 `WeightedGraph`（或由 `GraphService` 重建，二者选一，不要各存一份）。
- `add`：生成 `maxId + 1`，按当前参照城市插入链表，建 n 条边，`version++`。
- `update`：改名称/坐标；坐标变了要重算关联边、重排链表，`version++`。
- `delete`：删链表节点、删图节点和关联边，`version++`。
- `sorted(referenceId)`：`referenceId` 为空用 1000；参照城市被删则用 id 最小的城市；返回 `prevId/nextId`。
- `reset()`：重新读 `cities.txt`，`version++`。
- 校验放在 Service：名称唯一、坐标范围、id 不存在抛 `CityNotFoundException`、重名抛 `DuplicateCityException`。

### 3.2 GraphService（郝晟尧）

```java
GraphDTO graph();
List<AdjacencyDTO> adjacency();
WeightedGraph currentGraph();
void rebuild();
int version();
```

实现要点：

- 按 `CityService.version()` 缓存图；版本变了重建。
- `currentGraph()` 给 `MstService`/`PathService` 用，返回当前快照，不要在 Service 里改它。
- `graph()` 的节点 id 转字符串（G6 用）；`edgeCount` 用 `WeightedGraph.edgeCount()`。
- `adjacency()` 每城一行，邻居补名称；顺序稳定（按 id 或按边权）。
- `version()` 直接返回 `cityService.version()`，不要另起一个版本号。

### 3.3 MstService（郝晟尧）

```java
MstDTO compute(String algorithm);
```

实现要点：

- `algorithm` 只接受 `prim` / `kruskal`，其他抛 `IllegalArgumentException`。
- 调 `PrimMST.primMST(graph)` 或 `KruskalMST.kruskalMST(graph)`。
- `MstResult` 的 `Edge` 用 `getStartId()/getEndId()`，转成 `MstEdgeDTO(fromId, fromName, toId, toName, weight)`。
- 补 `graphVersion`；`totalWeight` 用 `MstResult` 已算好的值，不要重算。
- 连通时 `edgeCount = n-1`；不连通时是最小生成森林，`connected=false`。

### 3.4 PathService（郝晟尧）

```java
PathDTO shortest(int fromId, int toId, String mode);
```

实现要点：

- `mode` 只接受 `graph` / `tree`，其他抛 `IllegalArgumentException`；默认 `graph`。
- `DijkstraShortestPath.PathResult` 的 `path` 是 `List<Integer>`，补成 `PathNodeDTO(id, name)`。
- `cost` 直接用 `PathResult.getCost()`；`hops` 用 `getHops()`。
- 补 `graphVersion`；不可达 `found=false`、`cost=null`、`path=[]`。
- `tree` 模式在 MST 上跑；实现方式可以先用 Prim 求 MST，再在树上找唯一路径，或者后续补。

### 3.5 AuthService（黄予函）

```java
LoginResponse login(LoginRequest request);
UserDTO me(String authorization);
void logout(String authorization);
```

实现要点：

- 预置 `admin/admin123`（ADMIN）、`user/user123`（USER）。
- 登录成功生成 UUID token，存 `Map<String, User>`；服务重启失效。
- `me`/`logout` 解析 `Authorization: Bearer <token>`；没有/无效抛 `UnauthorizedException`。
- 不返回密码；`UserDTO.role` 用 `role.name()`。

## 4. Controller 对应

| Controller | 路径 | 方法 | 权限 |
|---|---|---|---|
| `AuthController` | `/api/auth` | `login` / `me` / `logout` | 登录公开，其余登录 |
| `CityController` | `/api/cities` | 列表/排序/详情/新增/修改/删除 | 读登录，写管理员 |
| `GraphController` | `/api/graph` | 图/邻接表 | 登录 |
| `MstController` | `/api/mst` | 生成树 | 登录 |
| `PathController` | `/api/paths` | 最短路 | 登录 |
| `AdminController` | `/api/admin` | 重置数据 | 管理员 |

Controller 只做三件事：

1. `@Valid` 校验请求体；
2. 调 Service；
3. `Result.ok(...)` 包装。

不要把 `try/catch` 写在 Controller；异常交给 `GlobalExceptionHandler`。

## 5. 公共约定

### 5.1 Result

```java
public record Result<T>(int code, String message, T data, List<FieldError> errors) {
    static <T> Result<T> ok(T data);
    static <T> Result<T> ok();
    static <T> Result<T> fail(ResultCode code, String message);
    static <T> Result<T> fail(ResultCode code, String message, List<FieldError> errors);
}
```

- 成功：`code=200`，`message="success"`，`errors=null`。
- 失败：`code` 与 HTTP 状态一致，`data=null`。
- 字段校验失败：`errors` 给 `[{field, message}]`。

### 5.2 异常映射

| 异常 | HTTP / code |
|---|---|
| `CityNotFoundException` | 404 |
| `DuplicateCityException` | 409 |
| `InvalidCoordinateException` | 400 |
| `UnauthorizedException` | 401 |
| `ForbiddenException` | 403 |
| `MethodArgumentNotValidException` | 400，带 `errors` |
| `IllegalArgumentException` | 400 |
| 其他 `Exception` | 500（日志里打堆栈，响应不露细节） |

### 5.3 认证

- 请求头：`Authorization: Bearer <token>`。
- 角色：`ADMIN` 可写，`USER` 只读。
- `@RequireRole(Role.ADMIN)` 标在写接口上；`AuthInterceptor` 读取并校验。
- 当前 `AuthInterceptor` 是**放行骨架**，黄予函补完后才真正 401/403。

### 5.4 graphVersion

- 唯一来源：`CityService.version()`。
- 任何写操作（增删改、reset）后 `version++`。
- `GraphService.version()` 直接返回它，不要另算。
- `MstDTO` / `PathDTO` 必须带 `graphVersion`。
- 缓存：MST/Path 结果按 `graphVersion` 缓存，版本不对就重算。
