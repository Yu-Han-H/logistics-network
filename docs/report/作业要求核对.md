## 2. 当前还需要注意的点

1. **控制台四类输出**  
   文档 1.5 要求 `cli/ConsoleRunner`，目前只有测试目录下的自检程序。建议补一个 `ConsoleRunner.main`，按顺序打印排序链表、邻接表、MST、路径，作为答辩兜底。

2. **邻接矩阵 vs 邻接表的报告段落**  
   文档 4.4 已有结论，但实验报告里最好单独写一段：30 城是完全图，矩阵 900 个单元也不大；作业要求邻接表，所以实现用邻接表；邻接表优势在稀疏图和只遍历邻居。

3. **严格“基于生成树”的口径**  
   现在 `mode=tree` 已真正使用 MST + Dijkstra；默认 `mode=graph` 仍然在原图上跑，这是文档 4.6 的选择。答辩时建议主动说明两种口径，并现场切 `mode=tree` 对照。

4. **前端页面尚未提交**  
   当前工作区的前端页面是未提交状态；提交后再按 Git 记录统计一次代码量，数字会变化。
